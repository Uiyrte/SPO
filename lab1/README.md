# Парсер метрик Холстеда (C#)

Программа с графическим интерфейсом для расчёта базовых и производных
метрик Холстеда (η1, η2, N1, N2, f1j, f2i, η, N, V) по исходному коду на C#.

## Требования

- macOS
- Python 3.12 с поддержкой Tkinter (через Homebrew)

Системный Python (из Command Line Tools) использует устаревший Tk 8.5,
который на новых версиях macOS может рисовать пустое окно. Поэтому нужен
Python из Homebrew с пакетом `python-tk`.

## Установка (один раз)

```bash
brew install python-tk@3.12
cd /Users/timofeykurstak/Desktop/BSUIR/SPO/lab1
/opt/homebrew/bin/python3.12 -m venv venv
```

Сторонние зависимости не нужны — используется только стандартная
библиотека Python (tkinter, re, dataclasses и т.д.).

## Запуск

```bash
cd /Users/timofeykurstak/Desktop/BSUIR/SPO/lab1
source venv/bin/activate
python main.py
```

Откроется окно приложения:

1. **«Открыть файл .cs»** — выбрать файл с исходным кодом C# (например,
   `Sample.cs` из этой папки — демонстрационный файл с разнообразными
   конструкциями языка).
2. **Область анализа** — переключатель:
   - «Весь файл» — анализируется весь текст файла;
   - «Только раздел операторов (тела методов)» — анализируются только
     тела методов/конструкторов/аксессоров и `=>`-выражений, без
     объявлений классов, полей, авто-свойств и `using`-директив
     (аналог требования методички анализировать только раздел
     операторов, а не раздел описаний).
3. **«Анализировать»** — запускает разбор; результат появляется во
   вкладке **«Таблица 2»**: частоты операторов (f1j) и операндов (f2i),
   итоговые η1/N1, η2/N2, а также словарь программы η, длина N и объём V.

## Структура проекта

| Файл | Назначение |
|---|---|
| `operators.py` | Реестр операторов и ключевых слов C# по категориям |
| `tokenizer.py` | Токенизатор исходного кода C# |
| `halstead.py` | Подсчёт метрик Холстеда по токенам |
| `gui.py` | Графический интерфейс (tkinter) |
| `main.py` | Точка входа — запускает GUI |
| `Sample.cs` | Демонстрационный файл с разнообразными конструкциями C# |

## Проверка без GUI (для отладки)

```bash
source venv/bin/activate
python -c "
from pathlib import Path
from tokenizer import tokenize
from halstead import compute_metrics

src = Path('Sample.cs').read_text(encoding='utf-8')
m = compute_metrics(tokenize(src))
print('n1', m.n1, 'n2', m.n2, 'N1', m.N1, 'N2', m.N2, 'V', round(m.volume, 2))
"
```
